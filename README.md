# QuickTrade - AI-Powered Marketplace for Lesotho

> An intelligent second-hand marketplace powered by AI to connect buyers and sellers in Lesotho.

## 🚀 Features

- **AI-Powered Price Suggestions**: Get real-time price recommendations with confidence scores (70-95%)
- **Market Trend Analysis**: Understand market trends (Rising, Falling, Stable)
- **Smart Matching**: AI algorithm matches buyers with relevant sellers
- **Trust Scores**: Community-based trust system for safe transactions
- **Urgency Indicators**: Know which items need to be sold quickly
- **Mobile-First Design**: Optimized for Lesotho's mobile-first market
- **Dark Mode Support**: Comfortable viewing in any lighting

## 🛠️ Tech Stack

### Frontend
- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript (strict mode)
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **State Management**: Zustand
- **Form Handling**: React Hook Form + Zod
- **Animations**: Framer Motion

### AI Integration
- **Price Prediction**: AI-powered suggestions with confidence scoring
- **Market Analysis**: Trend detection and demand scoring
- **Trust System**: User trust scores based on transactions
